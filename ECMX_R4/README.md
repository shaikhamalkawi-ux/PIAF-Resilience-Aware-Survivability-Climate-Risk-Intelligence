# ECMX-D-26-01378 - ECMX-R4 reproducibility package

Revised manuscript: **A Resource-Explicit Historical Climate-Stress Framework for Pre-Feasibility Photovoltaic Infrastructure Screening**

R4 is a bounded revision of R3. It preserves the verified NASA POWER evidence and baseline resource-climate screen, while adding the editorial closures required after independent audit:

- an explicit daily-data -> annual-metrics -> final-results code path;
- deterministic climate-component weight-path sensitivity;
- exact bootstrap Pareto-set frequencies;
- corrected interpretation of benchmark normalization;
- explicit engineering boundary for the wind descriptor;
- synchronized evidence registers and internal SHA-256 manifest;
- an explicit manifest verifier (`python scripts/verify_manifest.py`).

## Reproduce from an existing NASA daily-data directory

```bash
pip install -r requirements.txt
python scripts/run_all.py --daily-dir /path/to/NASA_POWER_2014_2023/daily_csv
```

## Reacquire NASA POWER and reproduce end to end

```bash
pip install -r requirements.txt
python scripts/run_all.py --acquire
```

The acquisition step requires internet access. The exact fixed coordinates, variables, dates, and query URLs are committed under `data/`. The separately archived raw NASA package used for the revision is recorded in `data/acquisition_metadata.json` with its SHA-256 digest.

## Main scientific boundary

The main screen is bi-objective: higher long-term mean GHI and lower baseline historical climate-context summary are preferred. The climate summary averages four benchmark-normalized descriptors with equal weights only as a declared baseline convention. R4 does **not** claim that these weights are calibrated or physically neutral. Component omission and deterministic one-component weight paths are reported so the shortlist's structural dependence is visible.

The four PV families - PERC, TOPCon, SHJ/HJT, and CdTe - are retained as evidence context only. No universal family coefficient or quantitative family ranking enters the empirical result.
